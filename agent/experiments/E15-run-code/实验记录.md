## 实验结论

对完整五次baseline，点估计提高；对同seed三次子集，点估计下降。不能只选择其中一个口径宣称稳定改善或退步。宇宙3/6在同seed对照中均分提高，1/2/4/5下降。约25.5%调用有代码错误，生成和修正代码占用研究预算；这是观察到的成本，不能断言为全部分差的唯一原因。

用户随后取消E17补跑，要求直接收束。E17在正式出分0场时停止，记录保留且不进入比较，不产生新的合并baseline。模型seed未固定，动作不同后相同环境seed不保证逐点噪声相同。

当前建议默认不加code：两种对照口径的点估计方向相反，未形成稳定收益证据；代码错误率约25.5%，生成与修正代码占用探索预算。保留工具作为实验能力，后续可优化输入接口、错误恢复及调用时机，但这不等于已证明工具永远无效。不会将与59.77的差值单独用作升级依据，也不将与68.08的差值当作严格因果效应。

# 提交版 v1

完整保留 official_test 的科研仓库源码。适配层负责官方接口、最多三个环境交互批次、请求与工具截止、反馈恢复和进程生命周期。仓库源码哈希由 repository-source.json 核验；这不表示适配后的整个控制流程与旧仓库实验完全等价。

## 运行配置

- Qwen3.8-27B，4 卡；300 秒探索总时限；每次输出上限 4096 tokens；thinking 关闭。
- 无累计 token 或模型调用次数配额。温度 0、top_p=1、top_k=-1，采样 seed=42。
- PySR 开启，run_code 关闭。依赖由镜像预装，提交包不含 Python/Julia/CUDA 环境。
- 最多三个环境交互批次，每个模型回复可含 1 至 8 项顺序工具操作，工具之间不追加模型调用；前两批用于探索，最后一批保留真实 submit。

## 交卷与截止

- 含噪声时，剩余时间不超过 90 秒，或同一候选的训练及独立验证位置 RMSE 均严格小于 0.01，才允许交卷。
- 最后 60 秒停止研究并仅允许 submit。请求前、回复后和批内工具执行前重新检查；本地计算与模型等待共享绝对截止，不通过重试延长原时钟。
- 研究模型请求保留最后 60 秒，且受原有单请求 95 秒上限约束。提交请求使用精简的当前会话候选上下文，每次最多 25 秒，保留 5 秒执行真实交卷。
- 超时、断流和临时响应错误返回控制循环，短退避也计入原时钟；恢复计数仅用于审计，不以固定次数提前放弃。认证、配置和实际配额错误不伪装为成功，也不重置配额。
- 不执行半截模型工具调用；中断的本地计算返回结构化失败。只有模型明确选择已有候选、claims 和说明，才能调用 submit；不自动制造候选或交卷。
- Console 实际返回 accepted=true 且 submitted=true 才确认交卷。此后 runner 发出的 SIGTERM 等待已有子服务清理，成功进程正常退出 0。

## 接口与依赖

积分与最终推演使用官方 rift.rollout；所有适配在 agent 内，官方 SDK/runner/根 models.json 保持原压缩包版本。科研工具的公式、拟合目标和参数约束不变。

镜像须提供可用的模型推理环境及离线 PySR/Julia 环境。支持通过 SHORE_PYSR_PYTHON 和已有 Julia 环境变量指定镜像预装位置；新的 Julia 缓存写入运行输出目录。启动预热在领取 mission 前完成。

有效交卷仍依赖本局获得可执行候选。超时恢复不保证物理规律正确，也不保证每个未知宇宙都能取得非零分。验收记录与分数放在包外的交付目录，避免混入提交资产。

# 固定观测滤波消融

## 实验 setting

E10 R07 六宇宙全部58条已采集轨迹，逐条固定输入；联合滤波与旧局部多项式对比。12条短轨迹回退旧路径。滤波参数、lambda网格和consumer源码均未修改。评估器独立生成公开世界的干净参考，仅用于事后计量，不传给滤波工具、Agent或PySR。

## 实验结论

位置误差六个世界都下降；加速度误差在1、4、6下降，在2、3、5上升。联合滤波会同时改变SR状态特征与导数目标，所以不能只根据某一个指标推断最终符号回归或Agent成绩。此实验仅度量固定输入的预处理效果；不代表新Agent已掌握规律，也不是官方榜单成绩。后续端到端成绩和实际调用率单列。
